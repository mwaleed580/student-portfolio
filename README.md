# University Student Clubs Portal

A collaborative web development project created as part of
the DevOps Fundamentals Fall 2026 assignment.

## Project Overview

The University Student Clubs Portal provides information
about student clubs, upcoming events, achievements, and
the process of joining university clubs.

## Technologies

- HTML5
- CSS3
- Git
- GitHub

## Team

Developed collaboratively by five students.

## Pages

1. Home
2. Club Categories
3. Upcoming Events
4. How to Join
5. Club Achievements

## Project Structure

- src/: HTML pages
- styles/: Shared CSS stylesheet
